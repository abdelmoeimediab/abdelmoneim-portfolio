خطوات رفع الموقع مجاناً وربطه بـ GitHub و Vercel و Supabase

تم تصميم هذا الموقع ليعمل فوراً بدون تعقيد، ويمكنك رفعه في 10 دقائق باتباع الخطوات التالية:

الخطوة 1 — GitHub

رفع ملف الموقع على GitHub

حمّل ملف الكود (index.html)، وافتح حسابك على github.com، أنشئ Repository جديد باسم abdelmoneim-portfolio وارفع الملف بداخله.

الخطوة 2 — Vercel

النشر المجاني عبر Vercel

ادخل على vercel.com وسجل دخولك بحساب GitHub، ثم اضغط Add New Project واختر المستودع abdelmoneim-portfolio ثم اضغط Deploy.

الخطوة 3 — Google Drive & Supabase

صلاحيات الفيديوهات وقاعدة البيانات

تأكد أن مجلد الفيديوهات على Google Drive مضبوط على Anyone with the link can view حتى تعمل جميع الفيديوهات الـ 19 لدى جميع الزوار مباشرة.

كود جدول قاعدة البيانات الجاهز لـ Supabase (SQL Editor): 
CREATE TABLE portfolio_projects (
  id TEXT PRIMARY KEY,
  title_ar TEXT NOT NULL,
  title_en TEXT NOT NULL,
  category TEXT NOT NULL,
  partner_id TEXT NOT NULL,
  drive_file_id TEXT,
  aspect TEXT DEFAULT '16:9',
  created_at TIMESTAMPTZ DEFAULT NOW()
);
