# Abdelmoneim Diab | Visual & Motion Lab — Portfolio & Case Studies

Official dual-language (`AR / EN`) Liquid Glass Portfolio & Client Case Study Web Application for **Abdelmoneim Ashraf Diab** (*Multimedia & Graphic Designer Specialist*).

## Included Files
- `index.html` — Complete self-contained web application (ready for Vercel & GitHub Pages).
- `vercel.json` — Zero-config Vercel deployment configuration.
- `supabase-schema.sql` — Ready-to-run PostgreSQL schema for Supabase SQL Editor.

## Quick Deployment (GitHub + Vercel)
1. Create a new repository on GitHub (e.g., `abdelmoneim-portfolio`).
2. Upload `index.html`, `vercel.json`, `supabase-schema.sql`, and `README.md` to the repository root and click **Commit changes**.
3. Log in to **vercel.com** with GitHub, click **Add New Project**, select `abdelmoneim-portfolio`, and click **Deploy**.
